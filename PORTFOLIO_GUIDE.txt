4. LINK vs NAVIGATE vs ROUTE

Link = SEE it <Link to="/about">About</Link> = door with sign
navigate() = CODE navigate("/contact") = invisible push, use when need logic
Route = MAP <Route path="/contact" element={<Contact />} /> defines pages

Rule: Menu item? Use Link. Button with logic? Use navigate(). Defining? Use Route

5. ROUTE MUST COME FIRST
